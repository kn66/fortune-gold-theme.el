# AGENTS.md

## Project

`fortune-gold-theme.el` is a warm light Emacs theme built on `modus-themes` and
`ef-themes`.

The theme identity is a fortune-oriented palette:

- yellow/gold as the primary accent
- warm white and beige as the base
- water blue, lavender, pink, red, orange, silver, and restrained green as
  supporting colors

## Files

- `fortune-gold-theme.el`: theme implementation
- `README.org`: user-facing overview and loading instructions
- `DESIGN.org`: palette, contrast, and implementation notes

## Dependencies

- Emacs 28.1+
- `modus-themes` 5.0.0+
- `ef-themes` 2.0.0+

In this local environment, dependencies may be available under:

- `/home/nobu43/.emacs.d/elpa/modus-themes-5.2.0`
- `/home/nobu43/.emacs.d/elpa/ef-themes-2.1.0`

## Validation

Load the theme in batch mode:

```sh
emacs -Q --batch \
  -L /home/nobu43/.emacs.d/elpa/modus-themes-5.2.0 \
  -L /home/nobu43/.emacs.d/elpa/ef-themes-2.1.0 \
  -L . \
  -l fortune-gold-theme.el \
  --eval "(load-theme 'fortune-gold t)"
```

Byte-compile:

```sh
emacs -Q --batch \
  -L /home/nobu43/.emacs.d/elpa/modus-themes-5.2.0 \
  -L /home/nobu43/.emacs.d/elpa/ef-themes-2.1.0 \
  -L . \
  -f batch-byte-compile fortune-gold-theme.el
```

`fortune-gold-theme.elc` is generated by byte compilation and is ignored by Git.

## Editing Guidelines

- Prefer palette and semantic mapping changes before adding direct face
  overrides.
- Keep direct face overrides in `fortune-gold-custom-faces` narrow and
  package-specific.
- Preserve the light-theme direction.
- Avoid pure yellow foreground on the light background; use ochre/gold-brown
  tones for readable yellow-family text.
- Keep syntax colors near WCAG AA contrast, roughly 4.5:1 to 5.5:1 against
  `#fbf7ed`, while keeping the main foreground higher contrast.
- Keep plain blue and green secondary because they had mixed fortune signals.
